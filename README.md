# Membangun Mindset Sehat - Web Slideshow

Presentasi interaktif tentang membangun mindset sehat untuk mahasiswa.

## 📦 File yang Disertakan

- **index.html** — Web slideshow (buka langsung di browser)
- **slide-01.jpg hingga slide-10.jpg** — Slide images
- **Membangun_Mindset_Sehat.pptx** — File PowerPoint original

## 🚀 Cara Menggunakan

### Opsi 1: Langsung Buka di Browser (Paling Mudah)
1. Ekstrak semua file ke satu folder
2. Double-click `index.html` atau drag ke browser
3. Presentasi siap!

### Opsi 2: Buka dengan HTTP Server (Recommended)
```bash
# Dari folder yang berisi index.html
python3 -m http.server 8000
```
Kemudian buka: `http://localhost:8000`

### Opsi 3: Deploy Online
Upload semua file (index.html + slide-*.jpg) ke hosting:
- **GitHub Pages** — Free
- **Vercel** — Free + fast
- **Netlify** — Free + easy
- **Firebase Hosting** — Free

## ⌨️ Kontrol

**Mouse:**
- Klik "Selanjutnya" / "Sebelumnya" untuk navigasi
- Double-click slide untuk fullscreen

**Keyboard:**
- `→` Slide berikutnya
- `←` Slide sebelumnya
- `Space` Slide berikutnya
- `Esc` Toggle fullscreen
